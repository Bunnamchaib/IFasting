# Activity insights

ฟีเจอร์เหล่านี้เพิ่มจากหน้าจอเดิม โดยยังเก็บรายการบันทึก ปุ่มแก้ไข กราฟเดิม และรูปแบบไฟล์สำรองไว้

## ทางลัดจากหน้าแรก

- แตะหัวข้อหรือตัวเลขน้ำหนักเพื่อเปิดหน้า **พัฒนาการ** ที่กราฟน้ำหนัก ปุ่มบันทึกน้ำหนักยังใช้เพิ่มรายการได้ตามเดิม
- แตะหัวข้อ **พักให้เพียงพอ** เพื่อเปิดหน้าการนอน

## ประวัติฟาสติ้ง

กราฟแสดงชั่วโมงในแต่ละวันย้อนหลัง **7 หรือ 30 วัน** รวมวันสิ้นสุดที่เลือก เป็นช่วงย้อนหลังต่อเนื่อง ไม่ใช่เดือนปฏิทิน ใช้เฉพาะรอบที่จบแล้ว รอบข้ามคืนแบ่งชั่วโมงตามวันท้องถิ่นที่เกิดขึ้นจริง ช่วงเวลาที่ทับกันนับเพียงครั้งเดียว รอบที่กำลังทำยังแสดงในตัวจับเวลา และจะรวมในกราฟเมื่อจบรอบ

เปิด **ดูชั่วโมงแต่ละวัน** เพื่ออ่านตัวเลข รายการแต่ละรอบพร้อมปุ่มแก้ไขยังอยู่ด้านล่าง

## น้ำดื่มรายชั่วโมง

เลือกวันที่เพื่อดูปริมาณรวมในแต่ละชั่วโมงตั้งแต่ 00:00 ถึง 23:00 ตามเวลาท้องถิ่น ชั่วโมงที่ไม่มีบันทึกแสดง 0 ml เปิดตารางเพื่ออ่านค่าทั้ง 24 ชั่วโมงได้ กราฟย้อนหลัง 7 วันและประวัติทั้งหมดอยู่ต่อจากส่วนนี้

## วันต่อเนื่อง

การ์ดล่างหน้าแรกนับ **วันที่มีรอบฟาสติ้งจบอย่างน้อยหนึ่งรอบ** วันละหนึ่งครั้งตามเวลาท้องถิ่น รอบข้ามคืนนับวันที่จบ หากวันนี้ยังไม่มีรอบที่จบ ยอดที่ต่อเนื่องถึงเมื่อวานยังคงไว้จนสิ้นวันนี้ หากเว้นวันจะเริ่มนับใหม่

จำนวนนี้บอกความต่อเนื่องของการบันทึกจบรอบ ไม่ใช่จำนวนวันที่อดอาหารติดต่อกัน และไม่ใช่เป้าหมายระยะเวลาที่ต้องอดให้ครบ

## บทเรียน Stage

แตะ **อ่านเพิ่มเติม** บนแต่ละ Stage เดิม เพื่อเปิดบทเรียนแยก พร้อมศัพท์เทคนิค ภาพ SVG สามขั้น ปุ่มเล่น/หยุดและขั้นถัดไป กลับแล้วคืนตำแหน่งเดิม รองรับภาษาไทย/อังกฤษและการตั้งค่าลดการเคลื่อนไหวของอุปกรณ์

บทเรียนอธิบาย insulin, glycogenolysis, lipolysis, ketogenesis, ketosis และ autophagy แบบย่อ ตัวจับเวลาไม่สามารถยืนยันระดับน้ำตาล คีโตน ฮอร์โมน หรือ autophagy ได้ แต่ละบทมีข้อจำกัดและลิงก์งานวิจัยประกอบ

## สำหรับผู้พัฒนา

เพิ่มฟังก์ชันบริสุทธิ์ `IFCore.fastingStreak`, `IFCore.fastingDays`, `IFCore.waterHours` และ `IFCore.localDay` โดยไม่เปลี่ยน schema หรือเวอร์ชัน IndexedDB ส่วนกราฟและบทเรียนอ่านข้อมูลอย่างเดียว ไม่เขียนประวัติสุขภาพ

รันทดสอบด้วย `node --test tests/*.test.cjs` ครอบคลุมรอบซ้อนทับ ข้ามเที่ยงคืน วันต่อเนื่อง การรวมปริมาณน้ำ และวันที่มี DST 23/25 ชั่วโมง รวมถึงเส้นทางหน้าจอและวงจรอนิเมชั่น
